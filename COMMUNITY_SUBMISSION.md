## Title
VEC Visual Cheatsheet Pack - twelve editable reference graphics for the Challenge

## What it is, in a line
Twelve editable visual references covering tasks, timelines, scoring, submissions, P3 and agent evidence.

## What it is, and who it helps
A coordinated set of twelve source-linked SVG/PNG/PDF cheatsheets that compress the Virtual Embryo Challenge into quick visual references: overall competition map, task layouts, T1/T2/T3 timelines, official scoring-question weights, valid H5AD anatomy, the P2-to-P3 transition, final-submission rules, and Agent Team evidence flow. The pack is designed for entrants, mentors, workshops and community channels: each graphic stands alone, uses no private data, includes a dated source footer, ships with editable SVG source, and has accessibility text. It helps participants answer common setup and scoring questions without rereading multiple rules/evaluation pages.

## How someone else uses it
Open the repository and use the ready-made PNG/PDF assets, or edit the source SVG files. No Challenge data, sign-in, or Python environment is required to use the finished visuals.
