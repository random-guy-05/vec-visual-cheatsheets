Each is available as **editable SVG**, high-resolution **PNG**, and single-page **PDF**. `VEC_VISUAL_CHEATSHEET_PACK.pdf` combines the whole set. Scientific/rules claims are source-linked in `docs/SOURCES.md`, and `docs/ALT_TEXT.md` provides accessibility descriptions.

These are community reference graphics, not official Challenge materials. If the official site changes after the source snapshot, the official site wins.
